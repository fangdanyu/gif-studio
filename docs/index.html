Features

一个 App 做完 GIF 的所有事

从"把视频变成 GIF"到"GIF 里的文字旋转 30 度"，六个入口 + 十一项编辑能力，都在同一个编辑页里闭环完成。

🎬

🖼️

多图合成 GIF

2~30 张图片，选完图直接成片（默认 200ms/帧），不再打断你去选帧率。

Highlights

三个最值得说的细节

这三件事是同类工具里最容易被做糙的：比例锁不住的裁剪、只能整块拖的文字、永远猜不到多大文件的导出。

裁剪 · 固定比例

选中 1:1 / 3:4 / 4:3 / 16:9 / 9:16 后，拖任意一个角，选框都只按该比例伸缩；四角控点向内收，不贴边好抓。

双指捏合 · 缩放 + 旋转

文字和 emoji 贴纸两指张开改大小、转动改角度，中心跟手；单指仍是拖动，右下角圆点仍是手柄。

按大小导出 · 先看体积

0.5MB~10MB 滑杆定目标，切换画质即时显示预估体积；导出时复用缓存，不再二次编码等进度条。

How to use

三步上手

没有账号、没有引导页、没有会员墙。装完直接进。

装 APK

下载 GifStudio-1.1.0-release.apk，允许"安装未知来源应用"后安装。

选入口

视频转 GIF / 多图合成 / 拍摄转 GIF / 打开已有 GIF / 模板库，任选一个。

编辑

裁剪、滤镜、速度、倒放、文字、贴纸、涂鸦、尺寸、删帧，随时改、非破坏。

导出

选画质或按体积、定循环次数，点导出；自动存相册与「我的作品」。

分享

结果页一键分享到微信 / QQ；也可在「我的作品」里再编辑。

  • 导出位置：相册 Pictures/GifStudio/，同名 GIF 会加序号不覆盖。
  • 再编辑：首页「我的作品」→ 选一条 → "再编辑"，图层与裁剪都会保留。
  • 体积档怎么用：选「按大小」→ 拖滑杆到目标（如 2MB）→ 导出；若目标过小，结果会显示真实体积而不是谎报达标。
  • 双指手势：先单指点选图层（出现橙色虚线框），再两指捏合缩放、转动旋转。
  • 固定比例裁剪：进裁剪 → 点 1:1 等比例 → 拖四角；换比例会重新居中取最大框。

支持的格式与限制

  • 导入：JPG / PNG / WEBP / GIF（含透明通道），长边统一限 720
  • 视频抽帧：最多 40 帧，宽度 320/480/640
  • GIF 导入：最多 64 帧，按倍数降采样控内存
  • 多图合成：2~30 张，默认 200ms/帧
  • 输出：GIF89a，支持透明与循环次数
Open source

开源与致谢

本项目的 GIF 编解码（GIF89a 编码 / 解码 / 中位切分量化 / LZW）全部自研，没有引入任何第三方 GIF 库；其余为 Android 官方与测试框架依赖，均为 Apache-2.0 或相应开源许可。完整清单（含用途与许可）见仓库根目录 THIRD_PARTY.md。

Kotlin AndroidX Core KTX AppCompat Material Components Activity KTX AndroidX ExifInterface JUnit 4 AndroidX Test Gradle / AGP Python Pillow（仅工具脚本）

仓库代码以 MIT 协议开源；APK 可自由分发，但署名与来源请保留「产品设计：FDY」。

技术要点

  • 自研编码：中位切分量化到 ≤256 色 + 15bit 缓存映射 + 标准 LZW
  • 自研解码：支持 GCT/LCT、隔行、GCE 透明、处置方式 0~3
  • 非破坏编辑：预览与导出共用同一套绘制管线，所见即所得
  • 核心体积：release 仅 4.2MB，无第三方图片框架
  • 交叉校验：与 Python Pillow 双向互认，逐像素 0 差异
